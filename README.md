# 🪙 Gold Bot (@funapp_game)

Telegram-бот: задания за голду, 11 мини-игр в чате, магазин призов.
Всё внутри чата бота, мини-аппа нет. Хостинг бесплатный — GitHub Actions 24/7.
Полное ТЗ — в [SPEC.md](SPEC.md).

## Запуск локально (2 команды)

```bash
pip install -r requirements.txt
BOT_TOKEN=123:ABC ADMIN_IDS=8396883978 python bot.py
```

Тесты: `pip install pytest && pytest tests/ -q`

## Деплой на GitHub (уже настроен)

1. Репо публичный (бесплатные минуты Actions 24/7).
2. Settings → Secrets → Actions: `BOT_TOKEN`, `ADMIN_IDS` (через запятую).
3. Actions → workflow «Run bot» → Run workflow.

Бот работает внутри воркера Actions, перезапускается каждые ~6 часов,
база `bot.db` автоматически коммитится в репо самим ботом.

## Админ-панель (мини-апп)

Синяя кнопка «Gold App» видна только двум админам (по Telegram ID).
Панель: задания, магазин, заявки, юзеры, рассылка (HTML + премиум-эмодзи),
статистика. Действия отправляются через sendData — для них открывай панель
кнопкой «Панель» (появляется после /admin): Telegram доставляет данные боту
только с keyboard-кнопки. Каждая операция проверяется по подписи initData
(HMAC) и Telegram ID. Команды (`/broadcast` и др.) тоже работают.

## Пополнение (Telegram Stars)

Кнопка «Пополнить» → пачки: 5⭐→50 G, 10⭐→110 G, 25⭐→300 G, 50⭐→650 G
(1 ⭐ = 10 G, бонус за объём). Оплата в Stars (XTR), зачисление мгновенное.
Звёзды бота можно вывести на Fragment.

## Админ-команды

`/admin`, `/addtask @канал 50`, `/deltask ID`, `/additem 150 Название`,
`/delitem ID`, `/tasks`, `/items`, `/requests`, `/done ID`, `/give ID 100`,
`/broadcast текст`, `/stats`

Премиум-иконки (пак Telegram iOS Icons) по умолчанию отключены: без Telegram
Premium у владельца они выглядят статичными фолбэками. Включаются секретом
PREMIUM_UI=1, когда у владельца появится Premium — тогда анимация видна всем.
